Research process:
1. Find 8 relevant reference websites.
2. Do not select websites only because they look visually impressive.
3. Prioritize websites with a similar business, audience, content density,
   and conversion goal.
4. Use Chrome DevTools MCP to open and inspect each shortlisted website.
5. Inspect desktop and mobile layouts.
6. Analyze:
   - information hierarchy
   - hero composition
   - typography scale
   - spacing system
   - grid and container widths
   - navigation
   - imagery
   - color usage
   - motion and scroll behavior
   - calls to action
   - mobile adaptation
7. Identify which patterns are appropriate for our project and which
   patterns would damage usability or performance.
8. Present the findings before modifying any code.

Then propose a redesign direction that combines suitable patterns from
multiple references. Do not copy a complete layout, branding, text,
illustrations, or assets from any single website.

After proposing the direction:
- Implement it in the existing codebase.
- Preserve the project's actual content and functionality.
- Reuse existing components where reasonable.
- Test the result at 390px, 768px, and 1440px.
- Use Chrome DevTools MCP to compare the implementation against the
  selected references.
- Fix overflow, weak hierarchy, inconsistent spacing, console errors,
  and unnecessary animations.
